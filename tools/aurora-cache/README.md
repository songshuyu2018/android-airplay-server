# Pre-rendered aurora assets

The optional player uses a GPU-native ASTC4x4 frame cache. Frames are independently zlib-compressed on disk, streamed off the GL thread into a fixed 24-buffer pool, then uploaded without a video decoder. Each band keeps four GPU texture slots. Birth and fade scheduling remains live in AuroraBeatCycle; alpha stores a radiance-weighted column reveal threshold, not display opacity. Stars, native output shading, far opacity and inexpensive global musical exposure remain live. Per-fibre musical brightness modulation is intentionally omitted in this mode.

The two band datasets are 1152x384, 256 volume samples, 480 temporal samples of a 30.76923077-second seamless loop. The 3:1 camera view is contained without horizontal cropping at aspects from 4:3 through 3:1, with a slightly elevated composition; 1:1 through 4:3 views gradually reveal 62% through 100% of the source width to retain curtain size; wider than 3:1 falls back to live rendering. Temporal interpolation keeps motion continuous at the user's output FPS. Each birth changes the band's starting phase by a deterministic offset while it is hidden. The two bands have independent offsets.

bake_reference.glsl is the offline fragment source. For frame i use loopPhase=i/480, time=12+4*sin(2*pi*loopPhase), and interpolate the 8 shape floats from AuroraMotion.writeGenerations(0,7) to writeGenerations(9,3) with weight .5-.5*cos(2*pi*loopPhase). Supply 256 depth-wind values using the existing AuroraDepthWind formula with z=1+i*7.8/255 (do not call its 96-count normalization). Use ages(.4,.4), zero music inputs, and fades(1,0)/(0,1) to render the two bands separately into RGBA8. Keep RGB unpremultiplied; alpha is metadata. The shader's carrier advances 16 integer noise cells per loop, with periodic corner hashes in Y; the sine shear and all geometry fields are periodic. This avoids a reset seam and cumulative spatial shear.

Encode the PNG frames with Arm astcenc -cl input.png output.astc 4x4 -medium. Do not use sRGB conversion or premultiply RGB by metadata alpha. pack_frames.py creates the indexed assets and manifest from those frames. astcenc is a build-time tool only and is not included in the APP. Its official releases are at https://github.com/ARM-software/astc-encoder/releases .

AUR3 layout (big endian): eight u32 values magic 0x41555232,version 3,width,height,count,blockX4,blockY4,decodedFrameBytes; f32 loop-wall-seconds; u32 volumeSamples 256; then count+1 u64 logical offsets. The index file contains only this header/table. Data are split at ceil(count/2) between suffix `_0`/`_1` assets; frame payloads are independent zlib streams containing ASTC blocks without the 16-byte ASTC file header. Logical offsets start just after the table; subtract the logical offset at each chunk's first frame to obtain its physical position. All assets must be stored uncompressed in the APK to permit bounded FileChannel reads. Header/chunk sizes and decompression completion are checked before use.

The assets occupy roughly 194MiB on disk, not RAM. The 24 CPU frame buffers use 10.13MiB, source compressed/raw scratch approximately 1.7MiB, and eight GPU texture payloads 3.38MiB, plus at most 1.69MiB for the near-composition target (driver overhead is additional). Expensive reveal/exposure work runs at source resolution; only the final stars/far/near combination runs at native resolution. Missing, unsupported or corrupt caches fall back to live rendering. The option defaults off; retain the existing quality/sample controls for fallback and comparison.

Reads and inflation are asynchronous, with an interleaved ten-frame window per band (about half a second ahead). Obsolete queued reads are skipped. GPU uploads do not hold the reader lock; four texture slots per band give uploads more distance from the frames still in flight.

The renderer, shaders and packaged assets are in `app/src/aurora/` and are compiled only by the Aurora flavor (`BuildConfig.AURORA_ENABLED=true`). The Standard flavor has no material assets or renderer sources. See `docs/build-editions.md` for build commands and CI package checks.
